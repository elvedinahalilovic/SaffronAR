# Saffron AR Educational App

An educational Android application about the saffron flower, developed using **Unity** and **Blender** as part of a Computer Graphics course project.

The application combines an interactive 3D model of the saffron flower with **Augmented Reality (AR)** to provide an engaging educational experience.

## Technologies

- Unity
- Blender
- C#
- Android

## Installation

The application is available for Android as an APK file.

1. Go to the **Releases** section of this repository.
2. Download the latest `.apk` file.
3. Install the APK on an Android device.


The AR functionality requires the reference image provided in this repository.

1. Open the AR reference image from the `AR-image` folder on another screen or print it.
2. Launch the application on your Android device.
3. Open the AR section of the application.
4. Point the device camera at the reference image.
5. The 3D saffron model will appear when the image is recognized.
